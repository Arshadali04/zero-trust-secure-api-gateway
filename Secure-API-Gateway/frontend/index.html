🔒 Zero Trust Security Flow

1. User authenticates via /api/login with credentials

2. Server validates credentials and issues a JWT token

3. Token is stored in browser and sent with every API request

4. Gateway verifies JWT on each request (reject if invalid/expired)

5. RBAC check: role-based permissions enforced per endpoint

6. Rate limiting applied (10 req/min per IP)

7. All requests logged for monitoring and audit

8. Response sent to user
